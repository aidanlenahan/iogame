# iogame
Archived 10/13/2026. Unarchived and re-archived 10/29/2026.<br>
Attempted remake at OpenFront game found at [https://openfront.io](https://openfront.io). Bailed as it was getting pretty boring, and the project came to a standstill. Started to work on [GEM](https://github.com/aidanlenaham/gem) as I started to bail on iogame. Was a decent attempt, and I learned that remaking games can be pretty monotonous and boring if you aren't entirely interested with the project.

**Play the static demo:** [aidanlenahan.github.io/iogame](https://aidanlenahan.github.io/iogame/). It runs entirely in the browser: `docs/engine.js` is an in-browser port of the backend that answers the frontend's `/api/*` calls, so no Node or Redis is needed. Rebuild the packed map seed with `node docs/tools/build_seed.js`.
